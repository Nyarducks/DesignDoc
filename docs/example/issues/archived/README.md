# Archived issues

Done, deferred, and wontfix issues move here — point-in-time records
kept for history. Each records its closing PR in `closed_pr:`
frontmatter. Frontmatter is optional on archived docs; when present it
is still validated. *(Fictional example — the Freightloop project.)*
